# The Road to Reality

Minecraft NeoForge 模组：从石器开局逐步走向冶金和工业化学。

当前已实现 **M0 石器时代的完整开局流程**：采集原料、燧石打制、捆绑工具、种植获取纤维、刮皮晾晒、钻木取火和篝火烹饪。M1 化学模型目前仍是独立 Java 原型；化学驱动的冶炼与机器属于后续里程碑。

## 运行

- Minecraft **1.21.1**、NeoForge **21.1.248**、Java **21**。
- 编译：`./gradlew build`（Windows：`./gradlew.bat build`）。成品位于 `build/libs/trtr-0.1.0.jar`，装入客户端和服务端的 `mods` 文件夹。
- 开发客户端：`./gradlew runClient`。
- 单元测试：`./gradlew test`；实际游戏逻辑测试：`./gradlew runGameTestServer`。
- GameTest 使用独立的 `run/m0-gametest` 目录；测试类和空测试结构不进入发布 jar。

## 开局

1. 打草和蕨类获取植物纤维；采集地面散石，挖砂砾获取燧石片。木棍可以通过树叶掉落或原版木板配方获得。
2. 手持燧石片或原版燧石，对空气右键打开打制界面。从边缘敲掉多余部分，保留描边的刃形，获得燧石刃。
3. 三份纤维搓一根植物绳，用绳、木棍和燧石刃组装工具。配方都可以在背包的 2×2 合成栏完成，获得相关材料后会解锁配方书。
4. 四份纤维合成干草束，配合原木制作未点燃的篝火。另一只手拿干草束，用钻木取火器对准篝火，持续按住右键四秒。
5. 用篝火烤食物；拿木棍右键已点燃的篝火获得火把。开垦种小麦，收获成熟小麦可以额外获得两份植物纤维。
6. 动物原本掉落的皮革改为兽皮。刮刀和兽皮分别放在两只手中，对空气右键刮制，再挂到晾皮架上。避雨晾干三十秒，右键收取原版皮革。

详细配方、行为边界和验收记录见 [M0 试玩与验收](docs/010-m0-playtest.md)。设计主线见 [项目总览](docs/000-overview.md) 和 [内容规划](docs/002-content-plan.md)。
