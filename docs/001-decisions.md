# 决策记录（ADR）

## ADR-001 加载器与版本：NeoForge 1.21.1

- 版本线 21.1.x（当前 21.1.248），构建插件 ModDevGradle 2.0.144，Gradle 9.7.1
- 理由：硬核科技生态主力版本；流体/能量/多方块基础设施成熟；NeoForge 对该版本长期维护
- Java 编译目标 21（toolchain 自动获取）

## ADR-002 化学深度：确定性反应为主

- 绝大多数反应为"条件满足 → 发生"：反应物配比、温度区间、催化剂、电位
- 少量动态量：炉温影响速率、电解槽用电位差判断能否电解
- 完整热力学平衡模拟（平衡常数、速率方程）收益低，采用静态查询表（分解温度、沸点等）替代

## ADR-003 化学品表示：数据定义 + DataComponent

- 物质 = 数据条目（id、化学式、元素组成、常温状态、染色、熔点、沸点等）
- 游戏内呈现：通用物品（粉末/晶体/锭）+ 通用流体，通过染色与名称区分
- 反应 = 数据文件（反应物、产物、条件），机器 = 条件提供者（温度/搅拌/电极）

## ADR-004 范围：仅无机化学

- 覆盖：冶金（还原/造渣/合金）、电解、酸碱盐、溶液化学
- 有机化学暂不实现

## ADR-005 采掘体系：连续硬度模型（推翻早期离散等级方案）

- 无采掘等级 enum：工具硬度 vs 岩石硬度（莫氏式连续值），效率与磨损由硬度差决定
- "挖不动"是涌现结果（速度趋零 + 崩刃），非硬性禁止
- 方法维度构成科技树：楔裂 → 火烧法（热应力）→ 钢钎 → 黑火药
- 原版方块经数据映射 MC 硬度接入，事件接管，不替换类
- 工具属性由成分计算（接 ADR-007）；原版配方默认禁用，由 trtr 配方系统接管
- 详见 docs/003-mining-system.md

## ADR-006 纯度系统：成分列表而非纯度百分比

- 物质栈 = 成分映射 Map<Substance, 摩尔量>（DataComponent），"纯度"是其视图
- 杂质来源：矿床特征（不同矿床杂质谱不同）、反应副产物（过量反应物/副反应）、容器残留
- 纯度作用：冶金（S/P 超标 → 工具脆化降耐久）、电化学（电极杂质 → 效率下降）、定量化学（催化剂纯度阈值、砷中毒）、溶液浓度（mol/L，浓稀行为不同）
- 提纯手段按时代递进：筛分 → 重结晶 → 蒸馏 → 电解精炼（阳极泥回收稀有金属）
- 呈现：tooltip 显示成分谱，颜色随纯度渐变
- 分期：M2 起步（粗炼带杂质 + 筛分），随里程碑逐层加深

## ADR-007 属性系统：标签归类 + 成分计算属性

- **标签层（静态）**：采掘等级（trtr:mineable/*）、反应物类别（trtr:reducing_agent 等）、杂质类别（trtr:impurity/*）；配方按 tag 匹配
- **属性层（动态）**：同材料工具不拆 item，ItemStack 挂材料成分快照（DataComponent），耐久/速度/采掘等级由成分在出炉时计算写入（利用 1.21 属性存于 ItemStack 的原生机制）
- 规则数据化（impurity_effects.json），调平衡不改代码
- 同一 MaterialProperties 系统复用于工具/导线电阻/催化剂活性/合金强度

## ADR-008 原版功能方块：四档重做

- 禁用：熔炉系/酿造台/TNT/切石（配方移除，非注册删除）
- 重造：工作台→工序台谱系、铁砧→锻打、炼药锅→化学容器
- 重调级：铁轨/矿车（M3+）
- 魔法搁置：trtr 工具不可附魔，附魔工具不入 trtr 配方，两线互不渗透
- 红石=信号层，trtr=功率层
- 详见 docs/008-vanilla-overhaul.md
