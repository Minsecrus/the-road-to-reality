# 采掘系统设计（M0）

## 核心理念：没有"挖不动"，只有"代价"

现实采掘由三因素决定，不存在离散等级：

1. **相对硬度（莫氏原理）**：硬物刻划软物；工具比岩石软 = 打滑磨钝
2. **代价**：时间 + 工具磨损，随硬度差连续变化
3. **方法**：没有更硬的材料时，用物理/化学手段绕过（火烧法、楔裂、炸药）

## 连续硬度模型

```
岩石：h_rock（连续，土 0.5 / 页岩 2 / 石灰岩 3 / 石头 4 / 铁矿 5.5 / 花岗岩 7）
工具：h_tool（燧石 6.5 / 铜 3 / 铁 4.5 / 钢 6）

效率 = f(h_tool − h_rock)
  > 0   正常切削，磨损 = 基础
  ≈ 0   极慢，磨损剧增
  < 0   速度趋零 + 崩刃加速（涌现式"挖不动"）
```

- 采掘能力/速度统一为一条曲线，无等级 enum
- 等级不足不弹提示——玩家从行为本身理解（速度、耐久条）
- 采掘速度计算接 MaterialProperties（ADR-007：成分 → 硬度/耐磨）

## 方法维度（科技树本体）

| 方法 | 原理 | 时代 |
|---|---|---|
| 敲击/楔裂 | 应力集中，软岩剥落 | 石器 |
| 火烧法 | 烧+淬冷 → 热应力开裂硬岩 | 掌握火（M2 起） |
| 钢钎+锤 | 高硬度材料直接切削 | M4 |
| 黑火药 | 化学能爆破（接硝酸工业） | M4 |

火烧法 = 第一个"化学战胜材料限制"时刻，机制与化学引擎同源（温度/淬冷）。

## 实现要点

- 事件接管（BreakSpeedEvent + 掉落判定），原版方块通过数据映射 MC 硬度 → trtr 硬度标尺，不替换类
- 岩石硬度、工具硬度均为数据；成分计算工具硬度
- 磨损模型：耐久消耗率随硬度差变化（负差急增）
- 保底：散石/软岩始终低硬度，开局路径畅通
