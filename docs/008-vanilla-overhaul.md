# 原版功能方块重做

## 裁决四档：保留 / 重造 / 重调级 / 禁用

| 原版 | 裁决 | 方案 |
|---|---|---|
| 熔炉/高炉/烟熏炉 | 禁用 | 窑炉谱系接管（柴堆→陶窑→竖炉→…） |
| 雕刻/切石 | 禁用 | 石工手工 |
| 工作台 | 重造 | 工序台谱系：木工台 / 金工台（锻打序列）/ 分拣台 / 实验台(M4)；2×2 手工合成收窄为捆绑搓绳类，部分配方改"按住数秒" |
| 铁砧 | 重造 | 锻打系统（加热→锻打→淬火） |
| 酿造台 | 禁用 | 药水=有机，ADR-004 边界外 |
| 附魔/经验 | 搁置 | 魔法线不碰；trtr 工具不可附魔、附魔工具不入 trtr 配方（两文明互不渗透） |
| 红石全套 | 保留 | 定位=信号层（逻辑）；功率层归 trtr 机械/电力 |
| 漏斗/管道 | 保留→渐进替代 | M4 被 trtr 物流超越 |
| TNT | 禁用 | 黑火药（硝酸线）接管 |
| 火把 | 保留 | 早期照明；矿灯为井下专业选项 |
| 铁轨/矿车 | 重调级 | 铁轨成本上调，M3 铁器后解锁，M4 机械化 |
| 炼药锅 | 重造 | trtr 第一件化学容器：盛液/加热/混合（M2 引擎入门教具） |
| 箱子/桶/床/门 | 保留 | — |
| 活塞/观察者 | 保留 | 红石逻辑件 |
| 农田 | 保留 | 化肥走石灰/硝石线 |

## 原则

- 禁用走配方移除 + 合成路径切断，非注册表删除（兼容性与存档安全）
- trtr 工具链与魔法互不渗透：两条文明路线并存
- 红石=信号，trtr=功率，两层各得其所
