# 岩石破裂与局部物理（M0~M4 贯穿）

## 原则：专用系统，不做通用物理引擎

体素世界 + 通用刚体物理 = 性能与复杂度黑洞。只做两个针对性系统。

## ① 岩石破裂系统（损伤模型）

岩石按损伤状态推进，非"血条归零消失"：

```
完整 → 微裂(累积) → 开裂(可见裂纹) → 破裂 → 碎石堆
```

- 方块隐藏损伤值，开裂阶段渲染裂纹贴图（原版龟裂蛋思路）
- 一切应力法写入同一损伤池，仅速率曲线不同：干凿慢 / 火烧法快 / 钢钎快而省 / 炸药一击必杀
- 淬冷（泼水于热岩）触发应力脉冲——火烧法两步操作（烧+泼）的机制支撑
- 采掘工具（003）与破裂系统对接：硬度差决定直接切削 vs 必须走破裂路线

## ② 局部重力规则

- **碎石堆**：1/8~1/4 格高堆叠方块，有重力、滑塌成自然堆角
- **顶板塌方**：悬空岩石超跨度概率塌落为碎石堆（砸伤+掩埋）——井下支护的真实动机
- 砂/砾/散石同规则

## ③ 碎石物料链（破裂之后）

```
碎石堆（需铲/筐装运，非秒拾取）
  ↓ 手选（分拣台：大块 vs 细末）
大块石料 → 再敲碎 / 建材
含矿细末 → 洗矿槽去泥 → 精矿
废石末   → 堆弃成矿渣山（环境代价可视化）
M4: 破碎机 → 球磨 → 标准粉料（粒度→反应面积→反应速率）
```

- 运输压力（重量/体积）是 M4 矿车/溜槽/提升机的因果来源
- 选矿从手选自然生长，非硬加机器

## 几何取舍

不做非方形方块。矿洞仍是体素剖面，底部铺不规则碎石堆软化机械感——真实感来自纹理层（碎石、滑塌、废墟），不是几何层。
