# 机器总目录（按单元操作组织）

机器 = 单元操作提供者。每台机器标注：提供的条件轴 + 结构形式（单方块/多方块）。

## 条件轴总表（化学引擎的输入维度）

| 轴 | 单位 | 由谁提供 |
|---|---|---|
| 温度 | K | 一切炉窑 |
| 气氛 | 还原/氧化/惰性 | 炉体密封性、燃料比 |
| 供氧/风量 | m³/s | 风箱、鼓风机 |
| 压力 | atm | 密闭容器（M4+） |
| 电位 | V | 电极 + 电源 |
| 搅拌 | — | 人力/水力/机械 |
| 接触时间 | s | 连续流 vs 间歇 |
| 分离力 | 沸点差/溶解度差/密度差/电极电位 | 各类分离设备 |

## M0~M1（无机器时代）

篝火（原始加热，温度上限极低）。操作靠手：敲击、捆绑、搓绳。
→ 机器空白期本身就是设计：让玩家体会"一切靠双手"。

## 汇总

- 机器总数 ~32 台，但归为 **7 个通用类**：炉窑类（温度/气氛）、破碎类、分离类、换热类、电化学类、动力类、通用釜
- 通用类一次实现，"新机器"多为数据+外形：如反射炉=炉窑类+隔焰数据；索尔维塔=吸收塔+结晶池的组合产线
- 机器的"成长"体现在同一类的新条件档位（柴堆→窑→反射炉 = 温度/气氛控制力递进），与 004 的智慧清单一一对应
