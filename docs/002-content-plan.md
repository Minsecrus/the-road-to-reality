## M1 化学引擎（纯代码，无游戏内容）

- Substance（物质数据模型：化学式/组成/状态/物理常数）
- Reaction（反应数据模型 + 求解器）
- 单元测试：电解水、CaCO₃ 分解、Fe₂O₃ 还原等基准反应
- 量纲：摩尔、浓度、温度(K)、能量(J)

## M2 火与铜——第一条化学链（含纯度系统起步）

新增：矿物带杂质谱（铜矿含 Fe/S）、粗铜冶炼保留杂质、筛分工序除不溶杂质、tooltip 成分谱显示

**物品**：木柴、木炭、陶罐、坩埚、铜矿石、粗铜、铜锭、铜工具全套(5)、陶范、黏土
**方块**：木柴堆、陶窑、坩埚炉、铜矿
**化学内容**：木材干馏(C→木炭+焦油)、黏土烧结、CuO/Cu₂S 还原、坩埚熔铜
**体验目标**：火 → 炭 → 陶 → 铜，全程化学驱动

## M3 铁与石灰——造渣冶金

**物品**：铁矿石、石灰岩、生石灰、铁块、粗铁锭、铁锭、铁工具全套(5)、风箱、竖炉部件
**方块**：竖炉、铁矿井下生成
**化学内容**：CaCO₃→CaO+CO₂、C+O₂→CO、Fe₂O₃+CO 还原、CaO+SiO₂→CaSiO₃ 造渣
**体验目标**：竖炉产铁块 → 锻打成锭

## M4 酸碱盐与电——工业化

**物品**：电解槽、蒸馏器、反应釜、发电机/电池、铅酸电池、电极(碳/铜/铁)、锡锭、青铜、钢、铝土矿、冰晶石、铝锭
**方块**：电解槽、蒸馏塔、反应釜、矿脉扩展(锡/铝土/盐)
**化学内容**：电解水、电解熔融盐制铝、食盐电解制 Cl₂/NaOH、硫酸工业(接触法)、盐酸/硝酸、溶液酸碱指示
**体验目标**：电力时代，工业量产
