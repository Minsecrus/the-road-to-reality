# 世界生成与村庄：文明同步原则

## 统一原则

世界与玩家文明同步：玩家的科技等级决定世界中的文明产物与 NPC 水平。不存在"越级获取"路径。

## M0~M2 荒野世界

- 禁用生成：村庄、掠夺哨站、沉船、埋藏宝藏
- 要塞/远古城市：保留结构，战利品池替换（无金属、无工具）
- 地牢/神殿/矿井箱子：战利品池分级——早期只出燧石/陶片/纤维/黏土
- 叙事：玩家是这个世界的第一个文明人
- 废弃矿井铁轨可拆除回收（废铁来源，合理）

## M3+ 移民系统

- 触发：玩家达到铁器时代 → 游民移民事件，请求定居
- 定居点从帐篷起步，随供给扩张
- 职业绑定 trtr 工序台：金工台(锻工)、鞣制架(皮匠)、实验台(药剂师)、分拣台(石匠)、竖炉/反射炉(盔甲匠)；木桶/织布机/堆肥桶沿用
- 交易方向：村民收购原料（碎石/矿石/化学品），出售劳动力与代工/搬运——是雇员，非科技贩卖机
- 职业池上限 = 玩家科技等级（铜器时代只来农民皮匠）

## 实施要点

- 结构禁用走数据包/世界生成配置，保留注册（存档安全）
- 战利品池替换用 loot table 覆盖
- 移民系统为 M3 内容，机制另详设
